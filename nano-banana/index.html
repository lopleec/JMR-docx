Nano Banana 专区

1/draw/nano-banana，支持 Gemini 官方接口格式。

Nano Banana 绘画接口

POST /v1/draw/nano-banana

请求头 Headers

{
 "Content-Type": "application/json",
 "Authorization": "Bearer apikey"
}

请求参数（JSON）

{
 "model": "nano-banana-fast",
 "prompt": "提示词",
 "aspectRatio": "auto",
 "imageSize": "1K",
 "urls": ["https://example.com/example.png"],
 "webHook": "https://example.com/callback",
 "shutProgress": false
}

参数说明

  • model（必填）：支持 nano-banana-2、nano-banana-2-cl、nano-banana-2-4k-cl、nano-banana-fast、nano-banana、nano-banana-pro、nano-banana-pro-vt、nano-banana-pro-cl、nano-banana-pro-vip、nano-banana-pro-4k-vip
  • urls（选填）：参考图 URL 或 Base64
  • prompt（必填）：提示词
  • aspectRatio（选填）：默认 auto，支持 auto/1:1/16:9/9:16/4:3/3:4/3:2/2:3/5:4/4:5/21:9；nano-banana-2* 额外支持 1:4/4:1/1:8/8:1
  • imageSize（选填）：默认 1K，支持 1K/2K/4K（不同模型有尺寸限制，分辨率越高生成越慢）
  • webHook（选填）：默认 stream；传回调地址则以 POST 回调进度与结果；若走轮询 result，传 "-1" 立即返回任务 id
  • shutProgress（选填）：boolean，默认 false，关闭进度只回最终结果（建议搭配 webhook）

webHook 返回

{
 "code": 0,
 "msg": "success",
 "data": { "id": "id" }
}

流式 / webHook 响应结构

{
 "id": "xxxxx",
 "results": [{
   "url": "https://example.com/example.png",
   "content": "这是一只可爱的猫咪在草地上玩耍"
 }],
 "progress": 100,
 "status": "succeeded",
 "failure_reason": "",
 "error": ""
}
  • status：running/succeeded/failed
  • failure_reason：output_moderation/input_moderation/error
  • url：有效期 2 小时

POST /v1/draw/result

 },
